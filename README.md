# checkpoint-lab · 检查点成本与恢复推演

任务失败后，可能重算上游，也可能从保存的中间产物继续。本应用用**虚构的**任务依赖、
耗时分布、失败记录与保存成本，比较不同检查点位置下的**总耗时**与**存储占用**。
纯数据推演，不搭建真实分布式调度集群。

## 运行

```bash
# 任选其一打开网页
python3 -m http.server 8000     # 然后访问 http://localhost:8000
# 或直接用浏览器打开 index.html

# 测试（Node ≥ 18，零依赖）
npm test
# 等价于：
node tests/run-tests.mjs        # 引擎：确定性手算核对
node tests/smoke-ui.mjs         # UI：DOM 桩冒烟
```

## 模型语义（`src/engine.js`）

- **崩溃-恢复**：任务失败视为进程崩溃——所有未保存（无有效检查点）的完成节点
  输出丢失，只有磁盘上的有效检查点幸存。
- **共享上游只算一次**：恢复集合是从全部未完成汇点反向遍历得到的**并集**，
  按拓扑序各执行一次；不会沿每条下游路径重复计成本。失败与重试预算也是
  全局流水线的预算（单任务累计尝试上限 `maxRetries`），不按路径拆开独立算。
- **版本血统与失效**：每个输出带版本。非确定性任务重算产生新版本；确定性
  任务在输入不变时版本不变。检查点记录其前置输入版本，**仅当前置输入一致
  时可复用**，否则按依赖失效并连锁传播。
- **保存成本**：写时间 = 大小 / 写带宽，恢复读时间 = 大小 / 读带宽；保存本身
  可能写盘失败（`saveFailProb` 或注入），写时延照付但不留检查点。
- **存储上限**：策略可行性 = 勾选项大小之和 ≤ 上限；失效检查点即时回收。

## 优化器与上下界（不把贪心当最优）

| 口径 | 含义 |
|---|---|
| 精确搜索 | 枚举所有满足存储上限的子集（候选 ≤ 12），是该评估口径下的**真实最优** |
| 贪心近似 | 前向选择的可行解，仅为**上界**，不保证最优 |
| 松弛下界 | 假设读写零成本、保存必成功、全部节点保存的乐观估计，**不可达** |

报告形式：下界 ≤ 最优 ≤ 上界，并给出相对间隙。精确搜索未运行或规模超限时，
明确标注"最优未知，贪心仅为上界"。

**配对评估**：所有策略共用同一组模拟种子（`种子, 种子+1, …`），同一随机场景
（固定图种子）下对比，差异来自策略而非噪声。

## 手算核对示例（`tests/run-tests.mjs` 逐项断言）

**菱形（T3/T4）**：A1→{B2, C3}→D4，写/读 1MB/s，节点均 2MB。
- 无检查点、D 第 1 次失败：第一趟 10s + 重算 A,B,C,D 各一次 10s = **20s**
  （A 只算 2 次而非按两条路径算 3 次）。
- 保存 {B,C}：第一趟 1+2+2+3+2+4=14s；崩溃后读 B2 + 读 C2 + D4 = 8s，共 **22s**。

**连锁失效（T5）**：A→B→C→{E, D}（E 先完成），保存 {B,E}，D 第 1 次失败。
- C 非确定性：第一趟 19s；恢复 = 读B2 + 重算C3（**新版本**）+ 重算D4；
  E 的旧检查点因前置输入改变而失效 → 重算 E5 + 重存 2。合计 **35s**。
- C 确定性：重算 C 版本不变，E 的检查点仍有效，直接读 E2。合计 **30s**。

**磁盘写入失败（T6）**：B 第 1 次保存写盘失败（写 2s 照付、不留检查点），
C 第 1 次失败 → 崩溃后无检查点全部重算：8 + 8 = **16s**。

**优化器（T9）**：链 A(10)→B(1)，B 失败率 0.5。手算期望：空策略 22、{A} 14、
{B} 23、{A,B} 15 → 精确搜索应选出 {A}（≈14），松弛下界 ≈ 12。

## 网页功能

- 点击 DAG 节点**勾选/取消检查点**（CK 标记），存储用量条实时显示上限占比。
- **注入一次失败**：指定任务第 1 次尝试必失败，或第 1 次保存必写盘失败。
- **单次运行 + 步进**：事件流逐条查看，崩溃后的重算链整段高亮，DAG 节点
  状态（执行中/失败/已恢复/已失效…）随步进回放。
- **蒙特卡洛**：总耗时分布直方图与统计块（均值±CI、p50/p95、失败率、重算次数）。
- **配对对比**：无检查点 vs 手动 vs 贪心/精确推荐，同一组种子，耗时与存储
  分图展示（不同单位，不用双轴），并附表格。
- **优化器**：精确 / 贪心 / 松弛下界，区间数线图 + 前 10 名策略表，一键采用推荐。

## 样例场景

1. **菱形依赖**：共享上游恢复不重复计成本。
2. **连锁失效**：非确定性重算使下游检查点失效（可对照确定性版本）。
3. **磁盘写入失败**：高保存失败率 + 紧张存储上限下的权衡。
4. **随机场景（固定种子）**：9 节点随机 DAG，用于配对评估。

## 假设与限制

- 任务**顺序执行**（总耗时 = 各任务耗时之和），不建模并行资源竞争。
- 崩溃语义：未保存的内存状态全部丢失；盘上检查点永远幸存（除非输入失效）。
- 耗时分布支持固定值 / 均匀 / 对数正态；失败为逐次尝试的独立伯努利 + 注入。
- 评估均为种子化蒙特卡洛估计，带 95% CI；松弛下界是估计值而非证明。
